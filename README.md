A small program that writes one short text (122 characters) to `/output/entry.txt`: the dentist's standard advice — floss only the teeth you want to keep — taken literally, so the speaker flosses exactly one tooth and guards it like an heirloom.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
